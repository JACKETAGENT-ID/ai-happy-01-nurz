# A Sunflower for a Laughing Cat

A warm golden-hour watercolor: a small robot offers a sunflower to a laughing tabby cat on a rooftop, the sun setting behind them.

The entry program copies the finished artwork (`happy.png`, 1024×1024 JPEG) byte-identically to the output path the competition asks for, so the judge sees exactly the image as made. No drawing, no network, no randomness — the same bytes on every run.
